# AI Mystery Room

An interactive, fictional detective game. Describe a scenario, investigate a case generated by Google Gemini, compare the clues, and submit one final accusation. The server keeps the culprit private until that accusation is recorded.

## Requirements

- Node.js 20 or later and npm
- MongoDB 7 or later, running locally or available through a connection URI
- A Google Gemini API key and a supported model name for case generation

## Run locally

1. Copy `.env.example` to `.env` in the repository root.
2. Set `MONGODB_URI`, `GEMINI_API_KEY`, `GEMINI_MODEL`, and a long random `SESSION_SECRET`.
3. Install dependencies with `npm install`.
4. Start MongoDB, then run `npm run dev`.
5. Open `http://localhost:5173`. The API health endpoint is `http://localhost:5000/api/v1/health`.

The application intentionally does not replace a failed Gemini call with a demo mystery. If credentials or MongoDB are missing, the interface reports a recoverable setup error. Hints have deterministic, evidence-based fallbacks. Media evidence is rendered as clearly labeled fictional/simulated evidence and does not imply that an image or video provider created an asset.

## Environment variables

| Variable | Purpose |
| --- | --- |
| `NODE_ENV` | Runtime mode; production enables secure cookies and requires a strong session secret. |
| `PORT` | Express API port (default `5000`). |
| `MONGODB_URI` | MongoDB connection string. |
| `GEMINI_API_KEY` | Server-only Google Gemini API credential. |
| `GEMINI_MODEL` | Gemini model supporting JSON structured output; set after checking current Google model availability. |
| `CLIENT_URL` | Exact frontend origin allowed by CORS and origin checks. |
| `SESSION_SECRET` | Secret used to sign anonymous session cookies. |
| `SESSION_COOKIE_NAME` | Name of the signed, HttpOnly session cookie. |
| `AI_REQUEST_TIMEOUT_MS` | Generation timeout (default `60000`). |
| `MAX_GENERATION_REPAIR_ATTEMPTS` | Bounded schema/consistency repair attempts (maximum `2`). |
| `ASSET_STORAGE_PROVIDER` | Reserved provider setting for a future media integration (`local` by default). |
| `ASSET_BASE_URL` | Reserved stable base URL for media assets. |

Never commit `.env` or expose Gemini credentials to the browser. Production requires HTTPS, a secure session secret, a production frontend origin, and a configured MongoDB service. Configure the hosting platform to allow credentialed cross-origin requests between the selected frontend and API origins.

## Architecture

- `client/`: React/Vite interface, routes, investigation dashboard, and Fetch API client.
- `server/`: Express API, signed anonymous sessions, rate limits, CSRF origin checks, Gemini generation, Mongoose models, and public response serializers.
- `specs/`: project, API, data model, AI, and acceptance-test references derived from `spec.md`.

Gemini requests and final answer evaluation run only on the server. Active case serializers omit the solution. Ownership checks use the signed session cookie on every case read and mutation. Evidence notes are escaped by React's normal text rendering.

## Commands

- `npm run dev` — start frontend and backend
- `npm run build` — create the production frontend bundle
- `npm test` — run backend and frontend unit tests
- `npm start` — start the API (MongoDB must be available)

## Deployment

The repository includes a Render Blueprint for a single-service deployment. Express serves the built React app and API from one HTTPS origin. Follow [DEPLOYMENT.md](./DEPLOYMENT.md) to connect GitHub, configure MongoDB Atlas and Gemini secrets, deploy, and verify the live app.

## Known implementation boundaries

- Image and CCTV records currently use labeled textual/simulated evidence; no image/video generation provider is configured.
- Anonymous history is available only while the browser retains its signed session cookie. An account migration path can later associate these cases with an authenticated account.
- Deployment smoke testing and verification against an actual Gemini model require credentials and infrastructure not included in this repository.
